I'm building Bailiwick Languages, an English-Spanish learning platform designed around real lessons, useful feedback, and clear support for families and teachers. I also work on application security research and open-source software.

## Selected work

### [Bailiwick Languages](https://github.com/jacobbabula/bailiwick-languages-demo) | in development

A bidirectional English-Spanish learning platform for elementary learners, with structured curriculum, practice, assessments, and linked family and teacher views. The wider product is still in development. Its browser-based AI integration is completed but experimental and continues to be tested across real devices.

`Next.js` `TypeScript` `PostgreSQL` `Supabase RLS` `WebGPU` `ONNX`

### [Bailiwick AI integration](https://github.com/jacobbabula/bailiwick-misty-qwen3-0.6b) | completed, experimental

The technical documentation and evaluation work behind Bailiwick's browser-local tutor. The integration runs directly in the browser and is complete as a product feature, but the AI itself remains experimental. It can explain and guide; grading, permissions, publishing, and learner progress stay under normal application controls.

`Transformers.js` `ONNX Runtime Web` `WebGPU` `AI safety`

### [Vulnerability research](https://github.com/jacobbabula/vulnerability-research)

Application-security research built around careful reproduction and responsible disclosure.
`Application security` `Source review` `Threat modeling` `Responsible disclosure`



## Current focus
